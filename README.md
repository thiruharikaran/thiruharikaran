## 🔍 VeriQore

**VeriQore** is a blockchain-powered certificate verification platform focused on secure and transparent academic certificate authentication.

### ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 **SHA-256 Hashing** | Generates a unique digital fingerprint for certificates |
| ⛓️ **Ethereum Blockchain** | Stores certificate hashes on Ethereum Sepolia |
| 📜 **Certificate Verification** | Enables instant certificate authenticity verification |
| ☁️ **Cloudinary Storage** | Securely stores original certificate documents |
| 👥 **Role-Based Access** | Separate portals for Master Admin, College Admin, Student and Recruiter |
| 📋 **Verification History** | Records recruiter verification activities |
| 🔑 **JWT Authentication** | Protects API endpoints and user sessions |
| 🚫 **Duplicate Detection** | Prevents duplicate certificate uploads before blockchain storage |
